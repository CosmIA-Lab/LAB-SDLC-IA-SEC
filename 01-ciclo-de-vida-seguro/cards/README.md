# Cartas de recall — ponto 1

Retrieval practice do ponto 1: abra `index.html` no navegador.

- A carta mostra a pergunta. Responda de cabeça, depois vire.
- Marque **Errei** ou **Acertei**. O que erra volta mais vezes na fila; o que acerta vai saindo.
- Cada carta mostra no topo o **tópico** e o **objetivo** (o que ela treina).
- Atalhos: `0` ou `espaço` vira · `1` errei · `2` acertei.
- Filtre por baralho:
  - **Sequência do argumento** — o ponto 1 inteiro, passo a passo.
  - **Taxonomia** — os quatro níveis: fundamento → princípio → técnica → mecanismo.
  - **Conceitos de base** — os fundamentos e princípios que valem em todas as fases.
  - **As cinco fases** — o ciclo de requisitos a deploy.

As cartas são extraídas do `README.md` do ponto. Se o README mudar, as cartas devem acompanhar.
