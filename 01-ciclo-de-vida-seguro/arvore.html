  FB["FALHA ≠ BUG
falha = desenho → reprojeto
bug = código → patch"]:::base
  B1["⟪ age cedo em TODO o ciclo →

  FUND["FUNDAMENTOS — 12 conceitos de base
CIA · assume breach · ameaça interna
defense in depth · least privilege · cadeia de suprimentos
sem obscuridade · superfície de ataque · sem segredo no código
zero trust · segurança usável · fatores de autenticação"]:::base
  B2["⟪ fixada a base, qual é o ciclo? ⟫"]:::bridge

  F1["1 · REQUISITOS — o que garantir
P: verificável · rastreável · negação explícita
T: abuse case (McDermott/Fox 99) · misuse (Sindre/Opdahl 00)
attack tree (Schneier 99) · bug bar (MS SDL)
→ requisito com teste"]:::fase
  F2["2 · DESIGN — desenho seguro antes do código
(fase mais barata; nasce a FALHA)
P: least privilege · defense in depth · fail secure · zero trust
T: modelagem de ameaças (Shostack 2014, 4 perguntas)
DFD (DeMarco 79) · superfície (Manadhata/Wing 04)
→ desenho com mitigações"]:::fase
  F3["3 · CÓDIGO — código sem falha conhecida
P: never trust input · nada hard coded · bounds checking
erro não ajuda o atacante
T: inspeção de Fagan (76) · secure code review (OWASP) · SAST no commit
→ código revisado + teste"]:::fase
  F4["4 · TESTES — falha com evidência
(7 alvos: código·app·infra·BD·APIs·integrações·rede)
P: evidência · severidade (bug bar) · cobertura dos 7 alvos
T: SAST · DAST · SCA · fuzzing · secret scanning · pentest
→ achado com severidade + prova + decisão"]:::fase
  F5["5 · DEPLOY + MANUTENÇÃO — detectar e responder em produção
P: assume breach · log sem segredo · detecção vale a resposta
T: resposta a incidentes (NIST 800-61) · gestão de vulnerabilidades
→ incidente contido → vira requisito do próximo ciclo"]:::fase
  FX["(extra) DESCONTINUAÇÃO — encerrar sem vazar
MS SDL / NIST SSDF · só checklist"]:::fase

  B3["⟪ processo escrito ≠ executado →
como garantir SEMPRE? ⟫"]:::bridge
  DSO["DEVSECOPS — Dev + Sec + Ops
responsabilidade compartilhada, automatizada, contínua"]:::ops
  SH["SHIFT-LEFT (push left por commit) + SHIFT-RIGHT (monitorar produção)
previne × detecta — um sem o outro deixa buraco"]:::ops
  PP["PIPELINE: commit→build→testes→análise(SAST/SCA/secrets)→staging→DAST→prod
regra de ouro: verificação falha → pipeline PARA"]:::ops
  TL["FERRAMENTAS: SAST(Semgrep) · DAST(ZAP) · SCA(Trivy) · secrets(gitleaks)
fuzzing · WAF/RASP (compram tempo, não corrigem)"]:::ops
